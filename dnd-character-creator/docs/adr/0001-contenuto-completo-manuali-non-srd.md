# Contenuto completo dei manuali base, non solo SRD

L'app è per uso personale (DM e giocatore, nessuna distribuzione pubblica). Abbiamo scelto di trascrivere nei data file (razze, classi, incantesimi, creature) il contenuto completo di PHB/MM/DMG 2014, non limitandoci al sottoinsieme SRD 5.1 liberamente redistribuibile. Se in futuro l'app venisse pubblicata o condivisa oltre la cerchia personale, questa scelta va rivista: il contenuto oltre l'SRD non è redistribuibile legalmente.
